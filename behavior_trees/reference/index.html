Behavior Trees — reference snapshots

The source the Behavior Trees deck quotes, and the recorded traces its interactive panels replay.

These are snapshots, not the implementation. Unlike every other module in this repository, this module's reference/ is not a runnable page: the system it teaches is the Rust publish-subscribe testbed pubsub_testbed_rs, a different repository. Slidev's <<< snippet importer cannot read outside its own workspace root, so each quoted file is carried here as a dated copy. Every file's header gives its source path, upstream length, commit hash, snapshot date, and the upstream line number of each #region marker — the header shifts every line down, so a line number in the copy is not the line number upstream. Edits belong upstream.
